## Run / Test

Install dependencies from the repo root (bskyembed is part of the root pnpm
workspace):

```bash
pnpm install
cd services/embed
```

Run the dev server:

```bash
pnpm dev
```

You can see the embed homepage at http://localhost:5173

### Testbed

In another terminal window, run the snippet dev script:

```bash
pnpm dev-snippet
```

You can then see the testbed page at http://localhost:5173/test
