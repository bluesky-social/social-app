# Release preparation demo

Generated by `node scripts/release/prepare-demo.mjs`. All 21 scenarios are self-checked.

This is a simulation using fixed fixtures, not the state of a real release. Branches, tags, candidate commits, and GitHub Releases exist only in memory. No Git commands, network requests, builds, translation operations, or publications are performed. Candidate IDs prefixed with `simulation:` are not Git SHAs.

The input source SHA is a fixture. The generated release document and draft body show the proposed content; the JSON report includes each simulated resource snapshot. Translation updates, real commit creation, and live GitHub integration remain unimplemented.
